# Home Assistant Notifications

A convenient way to get started with notifications for NOAH Guardra is to use a Home Assistant automation blueprint. You can use the YAML generated by the blueprint as a starting point and customize it for your installation.

It is generally recommended to trigger notifications from the `frigate/reviews` MQTT topic. This provides the event IDs needed to fetch [thumbnails, snapshots, clips, and other notification media](../integrations/home-assistant.md#notification-api).

The review data is published as a change feed, which means the previous state is available in the `before` section and the current state is available in the `after` section. See the [MQTT documentation](../integrations/mqtt.md#fr)
